# Fashion Gate landing platform — audit and implementation plan

Audit date: 2026-09-10. Working tree was clean. No AGENTS.md, WordPress installation, PHP CLI, Docker, or vercel.json was found.

1. **Existing application:** Next.js installed 15.5.20 (manifest ^15.3.4), React 19, App Router. Sanity project configuration lives in lib/sanity.ts. Existing redirects cover legacy blogs only; the dynamic /[lang] route can otherwise capture /landing. No existing landing code. Vercel uses next.config.ts. Do not touch existing UI, Sanity schemas, redirects, or contact handlers.
2. **Origin:** independent HTTPS WordPress, physically mounted at /landing. WP_HOME and WP_SITEURL both use the public /landing base. A signed static proxy credential distinguishes Vercel from direct origin requests; direct origin PHP is denied. Hosting must enforce the same credential for static assets. Public administration at /landing/wp-admin keeps Elementor preview, REST, cookies, generated CSS and AJAX on one origin. SAMEORIGIN replaces DENY only within /landing. This avoids dual-origin editor/generated-asset ambiguity.
3. **Routing:** opt-in Next middleware external rewrite, exact /landing subtree only, preserving path/query/method. Configuration is server-only; invalid origin configuration fails closed. No routing change until origin and proxy secret are configured. Initial Vercel deployment only; subsequent content changes are WordPress updates.
4. **Theme:** lightweight Astra child theme, Elementor Canvas for starter pages. Brand colors audited in app/globals.css: #CB6116, #9D430C, #050505, #101010, #F7F2EC, #B8AEA4, #fbfaf8. Cairo and Cormorant/EB Garamond are existing brand families. Do not redistribute the repository's personal-use-only Griphorium font.
5. **Elementor:** modern editable container trees, global kit tokens, independent section JSON imports. No monolithic PHP layout. Marketing role permits pages/media/templates without plugin/PHP administration.
6. **Pro:** optional licensed Forms, Theme Builder, Custom CSS, Popups. No purchase/activation. Core-compatible lead widget and in-page header/footer remain available.
7. **Extension:** isolated namespaced plugin with dependency guard, assets, motion controls, custom widgets, lead service and setup tooling.
8. **Widgets:** animated hero, horizontal showcase, reveal heading, editorial media, luxury cards, marquee, configurable lead experience; standard Elementor controls remain available.
9. **Motion:** Advanced > Fashion Gate Motion on standard widgets/containers, data attributes, bounded presets and visual controls.
10. **GSAP:** local pinned dependency, centralized progressive enhancement, matchMedia cleanup, editor/reduced-motion bypass, native mobile gallery, measured desktop travel.
11. **Leads:** server-validated Elementor field definitions, honeypot, signed timing token, atomic database rate gate, optional Turnstile. Configured email or authenticated webhook destination. Optional bridge maps to existing Sanity contact API without altering it; arbitrary form/attribution payloads require webhook or email to retain all fields.
12. **Analytics:** existing main site uses GA4 G-0GRFDMJBV6 and Meta pixel 1535285561613867 in app/layout.tsx; no GTM found. Rewritten WordPress HTML does not inherit these tags. Plugin emits allowlisted dataLayer events; deployment selects one tag owner. Consent uses the existing fashiongate_cookie_consent storage convention. No form values, URL queries, or click URLs in events.
13. **SEO:** require one established SEO owner (Yoast recommended if none installed), canonical/OG/sitemap URLs based on public WP_HOME, Polylang hreflang, truthful WebPage schema owned by SEO plugin, staging noindex and origin denial.
14. **Languages:** main site uses suffix /en and /ar, root redirects to Arabic (verified live). Landing uses Polylang's native /landing/ar/... and /landing/en/... directories to avoid a custom translation/router system; Arabic default root and paired translation links. Native WordPress lang/dir, Cairo Arabic, logical spacing.
15. **Caching:** no-store dynamic HTML/API/admin via origin and middleware; versioned static assets only. Elementor generated CSS cache regeneration and publish/refresh acceptance gate.
16. **Deployment:** packages and reproducible build scripts; host WP at /landing, configure secrets, install Astra/Elementor/SEO/Polylang, import templates, configure destinations, stage QA then enable Vercel routing.
17. **Testing:** local typecheck, JS syntax, template invariants, routing/unit tests, PHP lint if runtime can be provisioned. Live WordPress/Elementor role editing, browser matrix, real email/CRM, cache and public proxy acceptance must be performed on staging; never claim those passed from source inspection.

Live reference: https://www.fashiongatemall.com/ar and /en confirmed brand, location and department structure. No source video is needed; supplied written motion analysis is authoritative. No customer testimonials or scheduled events will be fabricated; reusable draft sections carry explicit editorial placeholders.
