# Marketing guide

**Normal Elementor edits do not require a Vercel deployment, Git commit, Next.js build or Sanity deployment.**

Log in at the public landing WordPress admin URL provided by your administrator. Use the Fashion Gate Marketing Manager account. All design sections are Elementor containers; you can replace the initial layout completely.

1. **Create a campaign:** Pages > Add New > choose language > Elementor Canvas > Edit with Elementor. Open the template folder, select My Templates, insert Fashion Gate — Immersive Lead Generation. Edit, Preview, then Publish. Connect its translation in Polylang.
2. **Add a section:** add Container, choose a layout, drag in any standard or Fashion Gate widget, then style it. Saved FG sections are starting points, not mandatory layouts.
3. **Move/delete/duplicate:** open Structure/Navigator; drag a container to reorder. Right-click > Duplicate or Delete. The header, footer and every campaign section can be changed independently.
4. **Hero and imagery:** select Animated Hero, change heading, text, buttons, image, mobile image and optional video. Use Media Library images with meaningful alt text; a decorative image may have blank alt. Review focal point, overlay contrast and responsive minimum height. Only one heading should use H1.
5. **Global design:** Site Settings > Global Colors / Global Fonts. Choose the FG tokens. Widgets connected to those tokens update together. Content, Style and Advanced panels remain available; set padding, gaps, widths, backgrounds and responsive typography normally.
6. **Responsive editing:** choose Tablet or Mobile at the top of Elementor; edit typography, spacing, ordering and visibility. Preview at narrow widths. Horizontal Showcase offers native swipe or stacked mobile cards; desktop pin is optional.
7. **Motion:** select any widget/container > Advanced > Fashion Gate Motion. Choose a preset, trigger, timing and device options. Keep mobile pinning off. Reduced-motion visitors always get a simplified version. Editor previews stay stable; use frontend Preview to see scroll effects. Do not also enable Elementor entrance animation on the same element.
8. **Forms:** select Lead Experience > Content > Form fields. Add, remove, duplicate or reorder fields; change labels, type, required flag and select options. IDs must be unique lowercase letters/numbers/underscores. Preserve `name`, `email`, optional `phone` if the administrator selected the existing contact adapter. Change campaign ID, button text and success/error messages. Destinations are administrator-managed secrets, not Elementor fields. New forms and fields require a real submission test. Insert the lead widget directly into the page/container; shortcode-embedded saved forms are not resolved by the custom endpoint.
9. **Pro forms:** when licensed, normal Elementor Pro Forms remain available. Their configured email/webhook actions are independent of the custom lead endpoint. The custom widget's timing/validation/attribution guarantees do not automatically apply to a Pro form; use the supplied lead widget for those guarantees until a Pro action adapter is configured and tested. Never equate a browser submit event with conversion.
10. **Languages:** create actual translated content, pair pages, choose Arabic/RTL or English/LTR. The header's language selector displays existing published translations only. Review direction, Arabic line breaks, form labels, email/phone direction and translated SEO.
11. **SEO:** use the installed SEO panel for title, description and social image. Keep canonical on the public domain. Remove unused headings and review schema against actual content. Do not publish sample testimonial placeholders or invented events.
12. **Safe publishing:** Preview first; save Draft for review. Duplicate a page before a major redesign. History > Revisions restores earlier content. Use staging for major structural changes. After Update refresh the public page, including on mobile, and verify the form still submits.

Reusable templates include hero, editorial intro, social proof, horizontal showcase, split story, category cards, immersive media, benefits, event enquiry, brand statement, lead form, FAQ, final CTA and dark footer in both languages. Testimonials are explicitly marked DRAFT and must be replaced with approved genuine content.

The campaign header/footer live inside the page by default. If your administrator enabled Pro Theme Builder, edit the assigned header/footer there instead. Popups are optional Pro features; no entry popup is shipped.
