# Fashion Gate WordPress platform

Installable Astra child theme, Elementor extension, bilingual template library and GSAP motion layer for the isolated `/landing` origin.

Start with [deployment](../docs/landing/DEPLOYMENT.md), [Marketing guide](../docs/landing/MARKETING.md), [developer guide](../docs/landing/DEVELOPER.md), [audit/plan](../docs/landing/IMPLEMENTATION-PLAN.md) and [QA](../docs/landing/QA.md).

Build: `npm ci --ignore-scripts && npm run build && npm test` from this directory. Package with `scripts/package.ps1`. Runtime requires independently hosted WordPress, Astra and Elementor. Pro features are optional and not bundled. No production credentials are included.
